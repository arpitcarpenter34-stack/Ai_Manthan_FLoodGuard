README file for field observation data associated with:

Blumensaat F., Bloem S., Ebi C., Disch A., Förster C., Rieckermann J., Maurer M., The UWO dataset contains open data from a full-scale field laboratory to better understand urban hydrological processes at small temporal and spatial scales - Open data for urban drainage applications. The Urban Water Observatory in Fehraltorf, Switzerland.

This package contains data slices from the field observations in Fehraltorf. The data are broken down by year of observation.
An additional file gives information about which package (A1-A4) a source belongs to.
A1 contains all precipitation and further meteorological variables, A2 all hydraulic measurements, A3 all temperature readings and A4 the complete wireless sensor network and its nodes.  

data_UWO_2019-01_2020-01.sqlite: contains field observation data from 1 January 2019 - 31 December 2019.   
data_UWO_2020-01_2021-01.sqlite: contains field observation data from 1 January 2020 - 31 December 2020.   
data_UWO_2021-01_2022-01.sqlite: contains field observation data from 1 January 2021 - 31 December 2021.   

data_uwo_sqlite_content_overview.csv: Information about which package (A1-A4) a source belongs to.  
	A1: contains all precipitation and further meteorological variables.  
	A2: all hydraulic measurements.  
	A3: all temperature readings.  
	A4: the complete wireless sensor network and its nodes.  
	

# How to access the data

Find sample queries in the related ERIC package UWO - Data access (2019 to 2021). Find it here: https://opendata.eawag.ch/dataset/uwo_data-access_2019_to_2021.
