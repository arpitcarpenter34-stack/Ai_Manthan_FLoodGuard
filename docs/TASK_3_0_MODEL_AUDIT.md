## 1. Executive Summary

This audit performs an exhaustive, code-level investigation into the existing machine learning models, graph neural network implementations, saved checkpoints, inference pipelines, and evaluation claims currently in the repository.

### Key Audit Findings
1. **Model Implementation Located:** The existing Hybrid ST-GNN is implemented in `backend/models/st_gnn_model.py` (442 lines), supported by `backend/models/spatial_graph.py` (graph matrices), `backend/models/temporal_pipeline.py` (time-series generation), and `backend/models/hybrid_prediction_engine.py` (hybrid reconciliation).
2. **Backbone Weights Are Randomly Initialized:** The graph diffusion convolution weights (`W_spatial`, `b_spatial`) and spatio-temporal GRU cell weights (`W_xr`, `W_hr`, `W_xu`, etc.) are **frozen Xavier uniform random initializations** generated with fixed random seeds (`np.random.RandomState(42)` and `43`). They were **never trained by gradient descent or backpropagation**. PyTorch is not installed in the environment.
3. **Only Readout Heads Were Fitted:** Only the 3 linear multi-task readout heads (`W_risk`, `W_depth`, `W_arrival`) were fitted using closed-form linear ridge regression ($\text{cov}^{-1} X^T y$) on top of recurrent states $H_{\text{train}}$.
4. **Source of Reported 97.1% Accuracy:** The reported $97.14\%$ accuracy is derived entirely from a **synthetic simulation dataset of 400 random storm events** generated by `temporal_pipeline.generate_chronological_dataset()`. It was **NOT evaluated on any real observational river, sewer, or rain gauge records**.
5. **Active Loaded Checkpoint:** The running FastAPI server and Streamlit dashboard load `data/st_gnn_model.npz` (37.3 KB) and read `data/st_gnn_evaluation_metrics.json` (1.6 KB).
6. **Legacy Model Status:** `data/flood_ml_model.joblib` (1.13 MB) is a legacy scikit-learn Random Forest classifier from earlier project iterations. It has been successfully deprecated and isolated from the primary inference flow.

## 4. Origin of the Reported 97.1% Accuracy

The reported $97.14\%$ test accuracy was audited by tracing `backend/models/st_gnn_model.py` and `backend/models/temporal_pipeline.py`.

### Forensic Trace
1. **Generating Function:** `temporal_pipeline.generate_chronological_dataset(n_events=400, random_state=42)`:
   - Storm intensity: sampled from exponential distribution `np.random.exponential(scale=30.0)` clipped to $[2.0, 130.0]\ mm/h$.
   - Flow propagation: simulated via the Rational formula $Q = (0.72 \cdot I \cdot A) / 3.6$ accumulating along the 7 Indore nodes.
   - Ground truth labels: synthetically generated via sigmoid thresholding:
     $$\text{is\_flood} = 1 \iff \text{uniform}() < \sigma\left(\frac{h - 72.0}{8.0}\right) \lor h > 82.0$$
2. **Dataset Partition:**
   - Total synthetic events: $400$ ($2,800$ node instances).
   - Training split: First $320$ events ($2,240$ node instances, $80\%$).
   - Test split: Last $80$ events ($560$ node instances, $20\%$).
3. **Head Calibration:**
   - Closed-form regularized ridge regression:
     $$W = (H_{\text{train}}^T H_{\text{train}} + 10^{-3} I)^{-1} H_{\text{train}}^T y_{\text{target}}$$
4. **Evaluation on 80 Synthetic Test Events ($560$ Node Instances):**
   - True Positives ($tp$): $431$
   - True Negatives ($tn$): $113$
   - False Positives ($fp$): $12$
   - False Negatives ($fn$): $4$
   - **Calculated Accuracy:**
     $$\text{Accuracy} = \frac{tp + tn}{tp + tn + fp + fn} = \frac{431 + 113}{560} = \frac{544}{560} = 0.971428... = \mathbf{97.14\%}$$
   - **Calculated F1-Score:** $0.9818$
   - **Calculated ROC-AUC:** $0.9948$
   - **Depth MAE:** $13.12\ cm$
   - **Arrival Time MAE:** $2.27\ mins$

### Scientific Verdict
The $97.1\%$ accuracy figure is **mathematically genuine for the synthetic simulation dataset on which it was measured**, but it is **NOT a validated metric of real-world hydrological forecasting**. It reflects the readout head's ability to fit the in-silico Rational formula simulation.
